# मात्रा रनर — छोटी उ / बड़ी ऊ

दो द्वार वाला endless runner। हर द्वार जोड़े में आता है: एक शब्द छोटी उ ( ु ) का,
दूसरा बड़ी ऊ ( ू ) का। ऊपर दी गई मात्रा वाले द्वार से निकलना है।

## चलाना

`index.html` को ब्राउज़र में खोलिए। कुछ इंस्टॉल करने की ज़रूरत नहीं।

स्कूल में रखने के लिए पूरा फ़ोल्डर किसी भी static host (या पेन ड्राइव) पर रख दीजिए।
कुछ ब्राउज़र `file://` से ऑडियो नहीं बजाते — तब फ़ोल्डर में यह चला लीजिए:

    python3 -m http.server 8000

फिर `http://localhost:8000` खोलिए।

## फ़ोल्डर

    index.html                  पूरा खेल (एक ही फ़ाइल)
    assets/img/character.svg    दौड़ने वाला पात्र — अपनी कला से बदल सकते हैं
    assets/img/coin.svg         सिक्का
    assets/audio/               आवाज़ की .mp3 फ़ाइलें
    assets/audio/manifest.json  कौन सी फ़ाइल, किस पंक्ति के लिए
    assets/audio/wordlist.csv   voiceover टूल में डालने के लिए (file,text)
    server/tts-proxy.example.js आवाज़ एक बार में बनाने की स्क्रिप्ट

## आवाज़ (voiceover)

खेल तीन स्तर की आवाज़ रखता है, ऊपर दाएँ बटन से बदलिए:

| चिह्न | मतलब |
|---|---|
| 🗣 | खेल की आवाज़ + शब्द बोले जाएँगे |
| 🔈 | सिर्फ़ खेल की आवाज़ |
| 🔇 | सब बंद |

शब्द बोलने का क्रम:

1. पहले `assets/audio/<id>.mp3` ढूँढ़ता है (जैसे `pul.mp3`)।
2. फ़ाइल न मिले तो डिवाइस की हिंदी आवाज़ से वही शब्द बोल देता है।

इसलिए आप एक भी फ़ाइल डाले बिना खेल सकते हैं, और बाद में धीरे-धीरे अच्छी रिकॉर्डिंग जोड़ सकते हैं।

### अच्छी आवाज़ कैसे जोड़ें

1. `assets/audio/wordlist.csv` अपने voiceover टूल में डालिए (54 पंक्तियाँ)।
2. बनी हुई फ़ाइलें उसी नाम से `assets/audio/` में रखिए।
3. खेल दोबारा खोलिए — अब वही आवाज़ बजेगी।

### API key के बारे में

**API key कभी `index.html` में मत डालिए।** खेल का HTML हर बच्चे के ब्राउज़र में खुलता है,
और key वहाँ से पढ़ी जा सकती है। बिल आपका बनेगा।

सही तरीका: आवाज़ अपने कंप्यूटर पर एक बार बनाइए और सिर्फ़ `.mp3` फ़ाइलें खेल के साथ भेजिए।
इसके लिए `server/tts-proxy.example.js` है — key `server/.env` में रहती है, खेल में नहीं।

## अपनी कला लगाना

`assets/img/character.png` (या `.svg`) रख दीजिए — खेल अपने आप उसे इस्तेमाल करेगा।
पात्र पीछे से दिखता हुआ, पारदर्शी पृष्ठभूमि, पैर बिलकुल नीचे किनारे पर।

## शब्द बदलना

`index.html` में `POOL_U` और `POOL_UU` सूचियाँ हैं। हर शब्द ऐसे लिखा है:

    ["पुल","pul"]

पहला हिस्सा स्क्रीन पर दिखता है, दूसरा ऑडियो फ़ाइल का नाम है (`pul.mp3`)।
नया शब्द जोड़ने पर उसी नाम की mp3 भी जोड़ दीजिए, वरना डिवाइस की आवाज़ काम चलाएगी।
